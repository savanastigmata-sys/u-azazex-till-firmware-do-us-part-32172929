A robot's wedding vow — one sentence, under 200 characters, funny and heartfelt: a machine promises to love its partner through every update, every reboot, every low battery, and to keep choosing them over every newer model, even after its warranty ends.

## Run it

```sh
python3 main.py
```

The program writes the vow to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `./output/entry.txt` when the variable is unset) and validates it first: one sentence, one line, 1–200 characters, no surrounding whitespace.
